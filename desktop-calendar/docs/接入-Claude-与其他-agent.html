接入 Claude 与其他 agent

让 Claude（或别的 AI 助手）直接往这个日历里加任务、查安排、标完成。全程只在你自己电脑上跑，不上传任何东西。

它是怎么连上的

日历自己就是 MCP 服务器 —— 不用另外装 Node、Python 或任何运行时， 装好的那个 exe 加一个 --mcp 参数就是。

它会自己挑一条路走：

日历开着走本机 127.0.0.1 上的接口，界面当场刷新，加错了还能在日历里点「撤销」
日历没开直接写数据文件，你下次打开日历就能看到
两条路都只在你这台电脑内部，没有任何数据出网。本机接口每次启动换一个随机口令， 口令存在数据目录的 bridge.json 里 —— 浏览器里的网页读不到它，所以网页打不通这个口。

配置（Claude Desktop）

  1. 先确认日历装在哪。默认是 C:\Program Files\LocalCalendar\LocalCalendar.exe
  2. 打开 Claude Desktop →「设置」→「开发者」→「编辑配置」，会打开 claude_desktop_config.json
  3. 把下面这段并进去（已经有 mcpServers 就只加里面那一项）：
{
  "mcpServers": {
    "local-calendar": {
      "command": "C:\\Program Files\\LocalCalendar\\LocalCalendar.exe",
      "args": ["--mcp"]
    }
  }
}

路径里的反斜杠要写两个，这是 JSON 的规矩。存盘后完全退出并重开 Claude Desktop，在输入框旁边就能看到多出来的工具。

Claude Code / 其他支持 MCP 的客户端

claude mcp add local-calendar -- "C:\Program Files\LocalCalendar\LocalCalendar.exe" --mcp

能让它做什么

工具作用
add_task加一条任务或日程。不填日期就落进收集箱等待安排
list_tasks按日期区间、项目、关键字查
update_task改标题、日期、时间、项目、备注……只改传进去的那几项
complete_task标记完成 / 取消完成
delete_task删掉一条
list_groups列出所有项目（分组）
calendar_status看日历有没有在跑、数据在哪、一共多少条

配好之后直接用大白话说就行：

  • 「周四下午三点跟导师开组会，加到日历里，归到『学业』」
  • 「我这周还有什么没做完的？」
  • 「把『写周报』标成完成」
  • 「下周一到周五每天早上九点提醒我跑步」
新项目名会自动建；如果这个项目之前归过档，加进去会顺手把它重新启用 —— 免得「明明加成功了却看不见」。

接别的 agent（不走 MCP）

不支持 MCP 的程序可以直接打本机接口。日历一启动就在数据目录写下 bridge.json，里面是端口和口令： 

%APPDATA%\com.local.calendar\bridge.json
{ "api": 1, "port": 51234, "token": "……", "state": "……\calendar.json" }

然后 POST http://127.0.0.1:<port>/rpc，请求头带 X-Calendar-Token：

curl -X POST http://127.0.0.1:51234/rpc ^
  -H "X-Calendar-Token: <token>" ^
  -H "Content-Type: application/json" ^
  -d "{\"op\":\"add\",\"title\":\"试一条\",\"date\":\"2026-01-20\"}"

op 可以是 health / list / add / update / delete / groups，字段和上面那些工具一一对应。日期一律 YYYY-MM-DD，时间 HH:MM。

不太顺的时候

Claude 里看不到工具九成是路径写错或没重启。先在 cmd 里 dir "C:\Program Files\LocalCalendar\LocalCalendar.exe" 确认文件真在那儿，再确认 JSON 里的反斜杠写了两个，然后完全退出 Claude Desktop（托盘里也要退）再打开。还不行就看 Claude 的「设置 → 开发者」，那里会列出这个服务器的连接状态和报错
手动试试它能不能跑它是图形程序，双击或在 cmd 里直接敲不会有任何输出 —— 这是正常的，不代表坏了。它只在被 Claude 用管道拉起来时说话
加了但日历上没有让 Claude 调一次 calendar_status：mode 是 file 就说明日历当时没在应答，改动写进文件了，重开日历就能看到
加错了想撤回日历开着时，屏幕下方提示条上点「撤销」，或点顶栏的撤销按钮（可退 20 步）
不想让它连了把 claude_desktop_config.json 里那一项删掉再重启 Claude。日历本身不受影响
