# Handoff: 本地日历应用 · 交互面板

## Overview

一个单窗口、纯本地运行的桌面日历 / 待办面板（980 × 620）。左侧是月视图，右侧是「未来 7 天」的待办分组清单，顶部是月份导航、日历分组图例、搜索、新建、主题切换与设置，底部是状态栏。面板内包含日详情浮卡、日程/任务编辑弹窗、区间框选批量操作条、右键菜单、操作反馈提示条（带撤销）。

目标形态：本地应用，无服务端。数据存本机（SQLite 或 JSON 文件），提醒走系统通知。

## About the Design Files

`prototype/` 里的文件是**设计参考**，用 HTML 做的可交互原型，用来表达最终的视觉与行为，**不是可以直接搬进产品的生产代码**。

任务是：在目标代码库的既有技术栈里（React / Vue / SwiftUI / Tauri + 前端 / Electron 等）**重新实现这些设计**，沿用该代码库已有的组件、状态管理与样式约定。如果还没有代码库，就先选定一个合适的框架（纯本地桌面应用推荐 Tauri 或 Electron），再按本文档实现。

原型文件使用了一个自定义的模板运行时（`support.js`），它只服务于设计预览，**不要移植它**。要移植的是布局、数值、状态机与交互逻辑。

- `prototype/交互面板 · 浅色.dc.html` — 完整原型（模板 + 逻辑类）
- `prototype/support.js` — 预览用运行时（仅为让原型能在浏览器打开，不是产品依赖）

用浏览器直接打开该 HTML 即可查看与操作。

## Fidelity

**High-fidelity（高保真）**。颜色、字号、间距、圆角、交互状态都已确定，应按本文档中的数值 1:1 还原。唯一允许替换的是：如果目标代码库已有设计系统，用其等价 token 映射本文档的颜色与间距。

## Screens / Views

### 1. 主面板

**布局**：纵向 flex — 顶栏（48px）/ 内容区（flex:1，横向：月视图 + 右侧栏）/ 状态栏。

#### 1.1 顶栏

左起：
- `‹` `2026年9月` `›`（24 × 24 图标按钮，悬停底色 `--c-panel`）
- `今天` 文字按钮（`--c-accent`，12px）
- 中部居中：分组图例，每项为「色点 + 名称」，点击切换该分组显隐；隐藏时色点变为空心（1.5px 描边、透明填充），文字变 `--c-faint`
- 右侧：搜索框（200 × 28，左侧放大镜图标，`placeholder: 搜索日程与任务`，聚焦时描边 1.5px 强调色）、橙色「+」新建任务按钮（28 × 28）、主题切换按钮、撤销按钮（无历史时 opacity 0.35）、设置按钮、关闭按钮

#### 1.2 月视图

- 星期行：周一起始，周六/周日文字为 `--c-faint`
- 单元格：日期数字在左上（17px 圆形，今天为 `--c-accent-soft` 底 + `--c-accent-deep` 字 + 700），非本月日期整体 opacity 0.3
- 单元格底色：本月工作日 `--c-bg`，本月周末 `--c-weekend`，非本月 `--c-other` / `--c-other-weekend`
- 条目最多显示 3 条，超出显示「+N 更多」（`--c-accent`，11px）
  - **日程（event）**：整块填充分组色，白字，11px/13px，圆角 4px；若是重复日程，标题前有 9px 循环图标
  - **任务（task）**：左侧 3 × 12px 分组色竖条 + 深色文字；已完成加删除线、opacity 0.4
- 每个条目都有原生 tooltip：第一行「时间 + 完整标题」，第二行「分组 · 每周重复 · 提醒设置」

#### 1.3 右侧「未来 7 天」栏

底色 `--c-panel`。标题「未来 7 天」。四个分组：已逾期 / 今明 / 3 天内 / 7 天内，每组标题 = 3px 色条 + 名称 + 数量徽章。

行结构：复选框（13–14px 方形，选中填充分组色 + 白勾）· 分组色竖条 · 标题 · 右侧剩余天数徽章（逾期 N 天 / 今天 / 明天 / N 天）。
悬停：整行底色 `--c-surface`，左侧色条从 4px 加宽到 6px。
**已完成的行排在各组末尾**（先按完成状态，再按日期）。

#### 1.4 状态栏

左：`今日 · N 个日程 / M 项待办`。右：`无期限 (N)` 可展开抽屉，列出无日期的条目。

### 2. 日详情浮卡（点击日期格）

宽 248px，最高 292px，锚定在该日期格右侧 8px；若该格靠近月视图右边界（left + 248 > 604），翻到格子左侧；上下居中并夹在 56 ~ 588px 之间。**没有遮罩、不压暗背景**，月视图与右侧栏全程可见。

### 3. 日程/任务编辑弹窗

420 × 460，居中，背后有 `rgba(43,37,33,0.35)` 遮罩。自上而下：

1. 标题栏：`新建日程 / 编辑日程 / 新建任务 / 编辑任务` + 「×」
2. 标题输入（高 30，描边 1.5px 强调色）
3. 一行：所属日历下拉（色点 + 名称 + 箭头，占据剩余宽度） | 「全天」开关（34 × 20 胶囊，开 = 强调色）
   - 下拉内容：未分组 + 所有分组；底部分隔线后是**新增分组**：名称输入 + 8 个配色圆点（选中项带 2px 表面色 + 3.5px 文字色的双层描边环）+「添加」按钮，回车亦可提交
4. 时间：日期字段（日历图标 + `2026/09/12`）+ 时间字段（时钟图标 + `14:30`，宽 88）
   - 日期字段点开内嵌月历：月份翻页、7 列日期网格、今天高亮、底部「清除 / 今天」
   - 时间字段点开双列选择器：左「时」00–23，右「分」00–55（5 分钟步进），底部「不指定 / 完成」
   - 全天开启时整行 opacity 0.45
5. 一行：地点输入 | 提醒下拉（不提醒 / 准时 / 提前 5 分钟 / 10 分钟 / 30 分钟 / 1 小时 / 1 天）
6. 备注多行输入（高 36，两行）
7. 分隔线
8. 重复区块：「每周重复」开关 + 「共 __ 周」数字输入（46px，仅数字，最多 3 位）+ 11px 灰字说明「将生成 15 条独立日程，可整组删除」；关闭时说明变为「仅这一条日程」
9. 底部：左侧「删除本条」「删除整组」（`--c-danger`，后者仅重复日程显示）；右侧「取消」「保存 / 创建」

所有浮层（分组下拉、日期选择、时间选择、提醒下拉）互斥，同一时刻只开一个。

### 4. 区间框选与批量操作条

- `每天各一条`（在区间每天各建一条任务）
- `跨天日程`（整段建成一条跨天日程）
- `改分组`（下拉，套用到区间内所有条目）

### 5. 右键菜单

宽 150px，跟随鼠标位置，靠边自动收进面板内。首行是灰色上下文标题（日期或条目名）。

- 日期格：新建日程 / 新建任务 / 清空这天（红）
- 条目：改到明天 / 改到下周一 / 复制到明天 / 标记完成（仅任务，已完成则为「标为未完成」）/ 编辑… / 删除（红）

## Interactions & Behavior

| 交互 | 行为 |
|---|---|
| 单击日期格 | 打开日详情浮卡（锚定在该格旁） |
| 单击月视图条目 | 同上（打开该天的浮卡） |
| 日详情内点条目 | 打开编辑弹窗 |
| 拖拽条目到别的日期 | 改期，落点格显示 1.5px 虚线强调框预览，完成后出提示条 |
| 横拖日期格 | 区间框选 → 批量操作条 |
| 右键日期格 / 条目 | 上下文菜单 |
| 搜索框输入 | 实时匹配标题 / 分组 / 地点，按日期排序，最多 8 条，首条高亮；回车打开第一条，点击某条跳到其所在月份并打开编辑弹窗 |
| 顶栏「+」 | 新建任务（默认今天） |
| 日详情「+」 | 在该天新建日程（默认 09:00、提醒提前 10 分钟） |
| 分组图例 | 点击切换该分组在月视图与右侧栏的显隐 |
| 撤销按钮 / 提示条撤销 | 回退最近一次数据变更（最多 20 步） |
| ←/→ | 翻月（**仅当鼠标在面板内或焦点在面板内**，避免误触） |
| Enter | 弹窗内保存（备注多行框内不触发） |
| Esc | 逐层关闭：右键菜单 → 框选 → 弹窗 → 日详情 → 设置/抽屉 → 清空搜索 |
| 设置菜单 | 显示已完成、显示非本月日期 两个开关 |

**易错点（原型踩过的坑，实现时注意）**

1. 不要用一层「透明遮罩」来做「点外部关闭」——它会吞掉用户那一次点击。应监听 mousedown（捕获阶段）判断点击目标是否在浮层内。
2. 框选结束后抑制那一次 click，必须在同一事件循环结束后立刻解除，否则会吞掉之后任意一次点击。
3. 全局键盘监听要判断焦点/鼠标是否在面板内。
4. 条目上的 mousedown 要阻止冒泡，否则拖动条目会被当成区间框选。

## State Management

```
year, month                 当前月份
tasks[]                     全部条目（见数据模型）
hidden{ 分组名: bool }       分组显隐
showDone, showOther         设置项：显示已完成 / 显示非本月日期
theme                       light | dark | blue
search                      搜索词 + 聚焦态
dayOpen, dayAnchor          日详情浮卡的日期与锚点矩形
modal                       编辑弹窗的完整草稿（含各浮层开关：
                            pickerOpen / timeOpen / groupListOpen / reminderOpen）
sel{start,end}, selActive   区间框选范围 / 是否已松手
ctx{kind,x,y,...}           右键菜单
toast                       提示条文案（5 秒自动清除）
history[]                   撤销栈，最多 20 步（每步是 tasks + hidden 的快照）
customGroups[]              用户新增的分组（名称 + 颜色）
```

撤销的做法：任何写操作前把 `tasks` 与 `hidden` 做一次浅拷贝快照压栈。真实产品里建议改成命令式 undo（记录操作而非全量快照）。

## 数据模型（原型用的形状，供参考）

```ts
type Item = {
  id: number;
  type: 'event' | 'task';
  group: string;            // 分组名，'' = 未分组
  title: string;
  date: string;             // 'YYYY-MM-DD'，'' = 无期限
  time?: string;            // 'HH:MM'
  withTime?: boolean;       // false = 全天
  location?: string;
  reminder?: string;        // '提前 10 分钟' 等
  notes?: string;
  done?: boolean;           // 任务专用
  priority?: '低'|'中'|'高';
  repeatOn?: boolean;       // 每周重复
  repeatWeeks?: string;
  spanId?: string;          // 跨天日程的分组键
  subtasks?: { title: string; date: string; done: boolean }[];
};
```

**做成真实产品时建议改动**（原型为了演示做了简化）：

- 重复日程：原型是「生成 N 条独立记录」。产品里应存一条规则（iCalendar RRULE）+ 例外表，才能支持「只改这一条 / 改本条及之后」。
- 跨天日程：原型是逐日拆成多条同名记录。产品里应是一条带 `start` / `end` 的记录，在月视图里横跨渲染。
- 时间字段：建议存 ISO 时间戳 + 时区，而不是 `date` + `time` 两个字符串，以正确处理跨时区与夏令时。
- 提醒：需要接系统通知与后台唤醒。
- 持久化：本地 SQLite 或 JSON 文件；建议同时支持 .ics 导入导出，以便和手机日历互通。
