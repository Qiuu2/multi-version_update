本地日历 · 使用说明

一个贴在桌面上的日历 / 待办面板。纯本地运行，不联网，不需要账号。

安装

  1. 解压下载到的压缩包，运行 LocalCalendar_x.x.x_x64-setup.exe
  2. Windows 会弹 SmartScreen 警告 —— 这是因为安装包没有购买代码签名证书，不是有问题。点「更多信息」→「仍要运行」
  3. 装完后从开始菜单启动，窗口会出现在屏幕右下角

另一个 .msi 文件是给批量部署用的，个人使用装 setup.exe 就行。

第一眼看到什么

一个没有标题栏的面板：左边是月视图，右边是「未来 7 天」的待办清单，顶栏有月份导航、分组图例、搜索框和几个按钮，底栏是今日统计。

拖顶栏的空白处可以移动窗口。

日程与任务

操作结果
点日期格打开当天的详情浮卡，看这天所有安排
浮卡里的 +在这天新建日程（默认 09:00，提前 10 分钟提醒）
顶栏橙色 +新建任务，默认落在今天
点条目打开编辑窗：标题、所属分组、全天开关、日期时间、地点、提醒、备注、每周重复
拖条目到别的格改期，落点会显示虚线预览
右键日期格新建日程 / 新建任务 / 清空这天
右键条目改到明天 / 改到下周一 / 复制到明天 / 标记完成 / 编辑 / 删除

日程是整块填色的（会议、活动这类有具体时间的），任务是左边一条细色条加文字（待办事项）。任务前面有复选框，做完打勾。

每周重复

编辑窗底部打开「每周重复」，填周数，保存后会真的生成那么多条独立日程。之后在任意一条上点「删除整组」可以整批删掉。

批量操作

在月视图上按住左键横拖过几个日期格，松手后底部会浮出操作条：

每天各一条在区间里每天各建一条同名任务
跨天日程整段建成一条连续的日程
改分组把区间内所有条目改到指定分组
删除 N 条删掉区间内所有条目

分组（项目）

顶栏中间那排带色点的就是分组图例，也是管理入口：

左键分组切换它在月视图和右侧栏的显隐（隐藏时色点变空心）
右键分组打开编辑浮层：改名、换色、只看这组、删除
末尾虚线 +新建分组

预置的四个分组只是初始数据，和自己建的完全一样，可以随意改名、换色、删除。

删除分组时会问你组内条目怎么办，三个选项：转为未分组 / 移到另一个分组 / 连同条目一起删除。选错了点提示条上的「撤销」就能回退。空分组会直接删除，不再多问。

贴在桌面上

点齿轮图标打开设置菜单：

桌面模式窗口压到所有窗口之下、从任务栏隐去，像桌面小组件一样待着
面板大小60% – 120% 调整整体尺寸，窗口跟着变
吸附到一键归位到屏幕四角，不会被任务栏压住
开机自启开机后自动运行
显示已完成 / 非本月日期月视图的显示开关

推荐用法：先调好面板大小 → 吸附到右下角 → 打开桌面模式。之后它就一直在那儿，不挡事。

桌面模式是「压在最底层的窗口」，不是壁纸。按 Win+D「显示桌面」时它会跟着被收起，这是正常的。

托盘图标

程序常驻在任务栏右下角的通知区域（可能被折叠在 ^ 里面，可以拖出来常驻）。

左键单击把窗口叫到眼前 —— 任何时候都有效
右键显示日历 / 隐藏到托盘 / 吸附到右下角 / 重置窗口 / 退出
面板右上角的 × 是「收进托盘」，不是退出。 真正退出请用托盘右键菜单里的「退出」。
万一窗口怎么都找不到，右键托盘 →「重置窗口」，它会关掉桌面模式、清空记住的位置、把窗口吸到右下角并拿到前台。

其它好用的

搜索框实时匹配标题、分组、地点。回车打开第一条，点某条会跳到它所在的月份
撤销顶栏的撤销按钮，或提示条上的「撤销」，可以退 20 步
← / →翻月（鼠标在面板内时才生效，避免误触）
Esc逐层关闭当前打开的浮层
底栏「无期限」展开没有日期的条目
配色顶栏那个半明半暗的圆，可切浅色 / 深色 / 蓝色

数据存在哪

所有日程存在这个文件里：

%APPDATA%\com.local.calendar\calendar.json

（在文件资源管理器地址栏粘贴 %APPDATA%\com.local.calendar 就能打开。）

  • 纯本地文件，关机重启不会丢
  • 不联网、不上传、不需要账号
  • 升级程序不影响它；卸载程序默认也不会删它
  • 想备份或换电脑，把这个文件复制走，放到新电脑的同一位置即可
目前没有自动备份。 如果这些日程对你重要，建议偶尔手动复制一份 calendar.json。

已知的限制

  • 提醒暂时不会真的弹通知 —— 提醒设置能存下来，但还没接系统通知
  • 安装包没有代码签名，所以每次给新电脑装都会遇到 SmartScreen 提示
  • 没有自动更新，升级需要重新下载安装包
  • 没有手机端，也不能和手机日历同步

法定节假日

月视图上会标出中国的法定节假日：红色的休是放假（放假第一天直接写节日名， 比如「国庆」），灰色的班是调休要上班的那个周末。鼠标停上去能看到整段假期的起止。 不想看就在齿轮菜单里关掉「显示法定节假日」。

放假安排是国务院办公厅每年单独发通知定的，农历节日和调休日都算不出来，只能照抄。 所以还没发布通知的年份不会有标记 —— 通知出来之后更新一版就有了。

让 Claude 帮你记

这个日历可以接上 Claude（或别的 AI 助手）：跟它说一句「周四下午三点跟导师开组会」， 它就直接写进日历，也能反过来问它「我这周还有什么没做完」。全程只在你自己电脑上跑。 配置步骤见同一个压缩包里的《接入 Claude 与其他 agent》。
